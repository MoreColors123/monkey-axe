Help

Colour key: blue headings group the topics; gold monospace is a field, value or file you can edit (e.g. cy, scale, rect_overrides); orange marks frames or rectangles that are borrowed or extra.

mode — bottom (feet on ground)

The whole animation is drawn at one size and each frame's feet sit on its anchor, cy (the anchor's y inside the frame). Use it for poses that stand: idle, walking, running, attacks, jumping.

mode — center (lying / airborne)

The sprite is fitted and vertically centred inside the frame, ignoring cy. Use it for lying or tumbling poses: thrown, knock_down, dying, dead, resting.

scale (per animation)

An optional size multiplier for the selected animation only. Leave it blank to use the global scale. 1.0 = 100%, 1.15 = 15% larger. Raise it if one animation looks too small, lower it if it clips.

global scale

The base size for every animation that has no per-animation scale. Tuned so Guybrush matches Ax's height (currently 1.15). Change it to grow or shrink the whole character at once.

frames, filmstrip and preview

The filmstrip and both previews show every sprite in the current animation's frame list, even when the game layout has fewer frames. Those extra frames are drawn in orange and labelled (extra): they show what you are building, but they only bake into the game once the layout has a rectangle for each frame.

Rectangles

The atlas is one image with a fixed slot per rectangle, and the game layout reuses rectangles between animations, so a rectangle can hold only one sprite. The first animation in layout order that uses a rectangle owns it; any other animation that draws it reuses the owner's sprite and its own choice is ignored (shown as borrowed).

The Rectangles bar under the animation list shows every rectangle with its owner and the sprite it currently bakes. To force one: select a sprite on the sheet, then press Set on a rectangle. That is stored as rect_overrides in mapping.json; Clear removes it.

After running deshare.py no rectangle is shared, so each animation owns its own and overrides are rarely needed.

Suggestions

Proposed mappings (written to suggestions.json by the agent) appear in the Suggestions bar: the proposed frame strip next to the animation's current frames. Open proposals come first, newest at the top; handled (approved/dismissed) ones are hidden unless you tick closed next to the section name (remembered per browser). Approve applies the proposal to the page (then Export mapping.json keeps it); Dismiss rejects it; Reopen re-opens a handled one. The comment box is saved back to suggestions.json for the agent to read - as are the statuses, which survive a reload when the page runs via serve_reviewer.py.

the sections

Sheet — the source sprite sheet (left). Animations — the list of animations (click one to edit it). Rectangles — the atlas-slot editor. Suggestions — the agent's proposed mappings with approve/dismiss/comment. Animation settings — mode/scale for the current animation. Preview — original vs new, playing together. Baked frames — what actually bakes. Frame list — the source sprites that make up the animation (editable).

controls and shortcuts

On the Sheet: click a box to select a sprite, double-click it to append it to the current animation, drag to pan and use the wheel to zoom.

Drag the divider between the Sheet and the panels to resize them; double-click the divider to reset. Undo is Ctrl+Z and Redo is Ctrl+Y (also Ctrl+Shift+Z).

Export mapping.json saves in place, keeping the previous file as mapping.backup.json, when the page is launched via scripts\ReviewSprites.bat; opened as a plain file it downloads instead.
